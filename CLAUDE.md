# Lucida — Base de Conhecimento

Esta pasta é a referência **canônica** da Lucida (negócio, produto, técnico, UI, regras, marketing).
Antes de responder qualquer coisa sobre a Lucida, consulte o [`INDEX.md`](INDEX.md) e abra **só** o doc relevante.
Não invente: se não estiver na base, diga que não está — não preencha lacunas com suposição.
A base descreve o que é verdade hoje; o código do `lucida-monorepo` é a fonte primária quando houver dúvida.

Esta pasta também é um **vault do Obsidian**, lido por gente. Link entre docs é markdown relativo,
nunca `[[wikilink]]` — o grafo e o `check-drift.sh` dependem disso. `.obsidian/` é config, não conteúdo.
